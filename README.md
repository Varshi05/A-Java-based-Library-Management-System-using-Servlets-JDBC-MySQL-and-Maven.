# Library Management System

A browser-based Library Management System built with **Java Servlets, JDBC, MySQL, HTML and CSS**, running on **Apache Tomcat 11**.

## Features
- **Add Book**: validated form, ID generated by MySQL (`AUTO_INCREMENT`)
- **View Books**: formatted table, empty-state message, database error handling
- **Update Book**: choose an ID, edit a prefilled form, save
- **Delete Book**: choose an ID, confirmation page, then delete
- Server-side validation, prepared statements, HTML escaping, friendly error pages (no stack traces shown)
- Responsive layout for desktop and mobile

## Technology stack
Java 17+ (developed on JDK 25) · Jakarta Servlet 6.1 (`HttpServlet`) · Apache Tomcat 11.0.x · JDBC · MySQL 8.0 · MySQL Connector/J 8.4.0 · HTML · CSS · Maven (WAR packaging) · VS Code · Git/GitHub

## Request flow
```
Browser -> Tomcat -> Servlet (validate input) -> BookDAO (JDBC, PreparedStatement) -> MySQL
                         |                                          |
                         +--- HTML response / redirect <------------+
```
- `com.library.servlet.*`: handle requests and responses
- `com.library.dao.BookDAO`: all SQL
- `com.library.util.DBConnection`: opens JDBC connections from `db.properties`
- `com.library.util.BookValidator` / `HtmlUtil`: validation and HTML output helpers
- `src/main/webapp/css/style.css`: all styling (change colors in the `:root` block)

## Prerequisites
| Tool | Check with |
|---|---|
| JDK 17 or newer (JDK 25 used) | `java -version` and `javac -version` |
| Apache Maven 3.9+ | `mvn -v` |
| Apache Tomcat 11.0.x (zip distribution) | folder exists |
| MySQL Server 8.0 + MySQL Workbench | Workbench connects |
| Git | `git --version` |

Set environment variables (Windows: Start menu > "Edit the system environment variables"):
- `JAVA_HOME` = your JDK folder
- `CATALINA_HOME` = your Tomcat folder (for example `C:\tomcat\apache-tomcat-11.0.x`)

## Database setup
1. Open MySQL Workbench and open your local connection (user `root`, port `3307`).
2. Open `database/schema.sql` (File > Open SQL Script) and run it (lightning-bolt icon).
3. Refresh the Schemas panel and check that `librarydb` > `Tables` > `books` exists.
4. Verify with `DESCRIBE books;`

## Configuration (database password)
1. In `src/main/resources/`, copy `db.properties.example` to `db.properties`.
2. Edit `db.properties` and set your MySQL password. The default URL uses port 3307.
3. `db.properties` is git-ignored. Never commit it.

## Build and run
From the project root (VS Code: Terminal > New Terminal):

```
mvn clean package
```
This creates `target/library-management-system.war`.

Deploy it (either way):
- Run `deploy.bat`, or
- Copy the WAR to `%CATALINA_HOME%\webapps\` yourself.

Start Tomcat in a console so you can see the logs:
```
"%CATALINA_HOME%\bin\catalina.bat" run
```
Stop it with `Ctrl+C` in that console (or `"%CATALINA_HOME%\bin\shutdown.bat"`).

Open: **http://localhost:8080/library-management-system/**

To redeploy after changing code: stop Tomcat (or leave it running), run `deploy.bat`, then refresh the browser.

## Troubleshooting
| Problem | Fix |
|---|---|
| `'mvn' is not recognized` | Install Maven and add its `bin` folder to PATH; reopen the terminal |
| `JAVA_HOME is not defined correctly` | Set `JAVA_HOME` to the JDK folder (not the `bin` folder) |
| Build error `release version 17 not supported` | Your JDK is older than 17; use JDK 17 or newer |
| 404 on the app URL | Check that the WAR is in `webapps`, Tomcat is running, and the URL ends with `/library-management-system/` |
| Port 8080 already in use | Stop the other program, or change the port in `%CATALINA_HOME%\conf\server.xml` |
| "db.properties not found" in logs | Create `src/main/resources/db.properties`, then rebuild and redeploy |
| `Communications link failure` | MySQL is not running or the port in `db.url` is wrong (should be 3307) |
| `Access denied for user 'root'` | Wrong password in `db.properties` |
| `Public Key Retrieval is not allowed` | Keep `allowPublicKeyRetrieval=true` in `db.url` |
| `Unknown database 'librarydb'` | Run `database/schema.sql` in Workbench |
| Blank or error page | Read the logs in `%CATALINA_HOME%\logs\` (`catalina.*.log`, `localhost.*.log`) or the console |

## Known limitations
- No login or user roles; anyone who can open the site can change data.
- Database password is stored in a local plain-text file (acceptable for a college project, not for production).
- `useSSL=false` is used for local development only.
- No pagination or search; all books are shown on one page.
- Uses plain `DriverManager` (no connection pool).
- No CSRF protection on the forms.
